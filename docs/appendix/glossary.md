# 用語集

| 用語 | 意味 | 登場する場所 |
|---|---|---|
| **プロトコル** | お互いの中身を知らなくても話せるようにする、共通の約束 | 全般 |
| **typing.Protocol** | Python で「形 (メソッド) が合えば OK」を表す型。構造的部分型 | 全般 |
| **JSON-RPC 2.0** | `method` と `params` で相手の操作を呼ぶ、JSON の書式 | 全般 |
| **Request / Response** | 返事が必要な呼び出しと、その返事。`id` で対応づける | 全般 |
| **Notification** | 返事のいらない一方通行のお知らせ。`id` が無い | 全般 |
| **stdio** | 標準入出力。親プロセスと子プロセスのやり取りに使う | ACP |
| **SSE** | Server-Sent Events。HTTP でサーバーから順にイベントを流す仕組み | A2A |
| **WebSocket** | ブラウザなどと双方向に通信し続ける仕組み | AHP |
| **Client (ACP)** | エディタなど、人が触る側 | ACP |
| **Agent (ACP)** | コーディングエージェント。エディタの子プロセスとして動く | ACP |
| **セッション** | 1 つの会話のまとまり | ACP / AHP |
| **ターン** | 1 回の依頼から、その完了までのひとまとまり | ACP / AHP |
| **stopReason** | ターンが終わった理由 | ACP |
| **capabilities** | 「これができます」という申告 | ACP / A2A / AHP |
| **ACP Registry** | ACP 対応エージェントの公式カタログ | ACP |
| **アダプター** | ACP 非対応のエージェントを ACP で話せるようにする翻訳役 | ACP |
| **opaque** | 中身が見えないこと。A2A の相手はこの前提 | A2A |
| **Agent Card** | エージェントの名刺。スキル・接続先・認証方法を書いた JSON | A2A |
| **Skill** | 名刺に書かれた「頼めること」 | A2A |
| **Task** | 仕事の伝票。ID と状態を持つ | A2A |
| **Message / Part** | 1 回分の発言と、その中身 (テキスト・ファイル・データ) | A2A |
| **Artifact** | 仕事の成果物 | A2A |
| **contextId** | 関連するタスクをまとめる案件番号 | A2A |
| **プッシュ通知** | 相手が Webhook で完了を知らせてくれる仕組み | A2A |
| **ホスト** | セッションの正本を持ち、複数の画面に配るプロセス | AHP |
| **チャンネル** | 購読できる単位。URI で表す | AHP |
| **スナップショット** | 購読したときにもらう、今の状態まるごと | AHP |
| **アクション** | 状態を変える唯一の方法。通し番号つきで配られる | AHP |
| **リデューサー** | `(状態, アクション) → 新しい状態` の純粋関数 | AHP |
| **write-ahead** | 自分の操作を先に画面へ反映し、後で答え合わせする方式 | AHP |
| **MCP** | Model Context Protocol。エージェントに道具を持たせる約束 | 比較用 |
| **プロンプトインジェクション** | 外部データに紛れた指示で、エージェントを操ろうとする攻撃 | 安全 |
